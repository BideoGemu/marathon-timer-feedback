# Marathon-Timer — Feedback

Bug reports and feature requests for **[Marathon-Timer](https://www.marathon-timer.com/)**, the free subathon timer and goals manager for Twitch, YouTube and Kick.

> 🇫🇷 Les signalements et suggestions en français sont les bienvenus.

This repository only hosts issues. The source code of the application is not published here.

## 🐛 Report a bug

Something does not work as expected? **[Open a bug report](https://github.com/BideoGemu/marathon-timer-feedback/issues/new?template=bug_report.yml)**.

What helps us fix it fast:

- the steps to see the problem ourselves;
- the platform involved (Twitch, YouTube, Kick, Streamlabs…);
- your channel name, so we can check what happened on your account;
- a screenshot or a short video.

## 💡 Suggest a feature

Got an idea? **[Open a feature request](https://github.com/BideoGemu/marathon-timer-feedback/issues/new?template=feature_request.yml)**.

Before posting, take a look at the [existing ideas](https://github.com/BideoGemu/marathon-timer-feedback/issues?q=is%3Aissue+label%3Aenhancement). If yours is already there, add a 👍 to it: it shows us what matters most to streamers.

## ⚠️ Issues are public

Anyone can read what you post here. **Never paste:**

- your sale or Ko-fi webhook URLs;
- tokens, API keys or verification tokens;
- anything copied from the *Connections* page.

If you are not sure whether something is private, leave it out. We will ask if we need it.

## No GitHub account?

You can reach us through the contact details on the [legal notice page](https://www.marathon-timer.com/en/mentions-legales).
